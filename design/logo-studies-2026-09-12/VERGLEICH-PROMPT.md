Use case: compositing.
Create a single clean, finished DESIGN COMPARISON BOARD using the four supplied images as the exact subject references. This is a presentation page, not an isolated logo export. Output a landscape 1536x1024 rectangular image. The whole canvas must be fully opaque matte charcoal #141516; background visible in all corners. No transparency or alpha anywhere. No photograph of a poster, no devices.
Layout: refined minimal 2x2 comparison board. Four equally sized cells with generous empty space. Fine muted gray horizontal and vertical rules divide the page quietly. Each cell contains one original white 3D sculpture, centered, and one short caption underneath. Keep object sizes visually balanced, approximately 290 pixels tall each; wide generous gutters, no touching borders.
TOP LEFT: Image 1, the three stacked faceted white rounded-square slabs. Caption exactly "01  STRATA".
TOP RIGHT: Image 2, the faceted white modular cube with the corner removed. Caption exactly "02  KERN".
BOTTOM LEFT: Image 3, the massive rounded D-like sculptural portal. Caption exactly "03  PORTAL".
BOTTOM RIGHT: Image 4, the four upright stepped white slabs. Caption exactly "04  REGISTER".
Top page heading in small tasteful off-white sans-serif exactly "DATABASE STUDIO". No other text.
Preserve the silhouette, geometry, relative arrangement, matte-white porcelain material, subtle broad faceting and soft pale-gray shading of each supplied object. Do not invent a fifth motif. Do not redesign the motifs.
Critical cleanup: all four reference objects have unwanted white flecks, ragged fringes, stray pixels and occasional colored slivers outside their silhouettes. Remove ALL these extraction artifacts. Render each real object edge clean, smooth and anti-aliased against the opaque charcoal background. The portal opening must show perfectly clean flat charcoal through it, with no stray flecks. No glow, no white halo, no outlines. Keep internal faces and shading intact.
Presentation is quiet, precise, premium. No brain, no network symbol, no current database icon, no added color, no decorations, no drop-shadow cards.
